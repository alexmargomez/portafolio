## 👨‍💻 Presentación

Hola, soy **Alexmar Gómez**, **Desarrollador de Software** enfocado en arquitectura **Backend** y desarrollo **Full Stack**, con más de **2 años de experiencia** construyendo software en producción, sistemas clínicos/hospitalarios, plataformas SaaS y herramientas de infraestructura.

### 🚀 Áreas de Especialidad

- **Arquitectura Backend & API REST:** Desarrollo y evolución de sistemas robustos con **PHP (Symfony, Laravel)**, **Node.js (Express, Fastify)**, **Python (Django)**, **JavaScript** y **TypeScript**.
- **Optimización SQL & Rendimiento:** Optimización integral de rendimiento en aplicaciones de alta concurrencia, generación de reportes complejos y afinamiento de consultas en **MySQL, MariaDB y PostgreSQL**.
- **Infraestructura Linux:** Administración de servidores **Linux VPS**, configuración de **Nginx**, proxies inversos, redes y seguridad SSL.
- **Contenedores Docker:** Orquestación y despliegue de entornos multicontenedor reproducibles con **Docker** y **Docker Compose**.
- **Automatización con Agentes de IA:** Diseño e implementación de flujos automatizados con **Agentes de IA** para migraciones masivas, validación normativa y despliegues continuos.
- **Desarrollo Frontend Moderno:** Construcción de interfaces reactivas y paneles administrativos con **React**, **Vue 3**, **Next.js** y **Tailwind CSS**.
